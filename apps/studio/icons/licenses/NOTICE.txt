Icons bundled with Metallic Studio
==================================

This folder ships beside Studio's executable (#291): the build copies it there, and Studio copies it into its own
folder (%APPDATA%\Metallic\Studio\icons on Windows) on start. Studio draws every built-in icon from the SVG that
icons.json names for it, in the colour icons.json gives its colour group; edit icons.json to change either. Icons are
not crates, so `cargo deny` does not see them: this file is their record.

explorer/, assets/, panels/, toolbar/, interface/ (#322)
  The SVGs, one folder per part of Studio that draws them: Lucide icons (https://lucide.dev), version 1.70.0,
  unmodified, named as Lucide names them (box.svg, scroll.svg, ...). An icon used in two parts is in both folders.

  Source: the npm package lucide-static 1.70.0 (https://registry.npmjs.org/lucide-static/-/lucide-static-1.70.0.tgz,
  sha1 5e8408d50248890e4262e79b8f7477056bbc2400, sha256 of the tarball
  3d1f09df1c468abe512ee6d6596db0dc773fa46c61050e365f0c5fee5120f16a), files icons/<name>.svg.

icons.json
  Generated from Studio's icon table (apps/studio/src/theme/icons/mod.rs) by
  `cargo test -p metallic_studio write_the_icon_manifest -- --ignored`; a test keeps it current.
