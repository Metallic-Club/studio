Fonts bundled with Metallic Studio
==================================

Studio draws all of its text and icons with the fonts in this folder (src/theme/fonts.rs); egui's own fonts are
never loaded. Each font keeps its licence text next to it, and packaging ships this folder's licence files with the
app. Font files are not crates, so `cargo deny` does not see them: this file is their record.

Inter-Variable.ttf
  Inter, variable (opsz 14-32, wght 100-900), unmodified, renamed from Inter[opsz,wght].ttf: the interface font
  (the website's, Metallic-Club/website). Studio draws it at weights 400 (body), 650 (controls) and 800 (headings).
  Copyright 2020 The Inter Project Authors (https://github.com/rsms/inter).
  SIL Open Font License 1.1, see OFL-Inter.txt (the OFL.txt shipped beside the font).
  Source: https://github.com/google/fonts/tree/main/ofl/inter, file Inter[opsz,wght].ttf (876,576 bytes,
  sha256 29160a80ff49ddcab2c97711247e08b1fab27a484a329ce8b813d820dc559031).

JetBrainsMono-Variable.ttf
  JetBrains Mono, version 2.304, variable (wght 100-800), subset to Latin, Latin Extended, punctuation, symbols,
  arrows, mathematical operators, box drawing and geometric shapes: code and changing numbers.
  Copyright 2020 The JetBrains Mono Project Authors (https://github.com/JetBrains/JetBrainsMono).
  SIL Open Font License 1.1, see OFL-JetBrainsMono.txt.
  Source: https://github.com/JetBrains/JetBrainsMono/releases/tag/v2.304, file fonts/variable/JetBrainsMono[wght].ttf.

Lucide.ttf
  Lucide icons (https://lucide.dev), version 1.70.0, the icon font, unmodified, renamed from lucide.ttf: every
  Studio icon (src/theme/icons.rs; the ids, groups and names are listed in docs/studio-icons.md).
  Copyright (c) 2026 Lucide Icons and Contributors. ISC License; the icons Lucide derives from Feather are also
  Copyright (c) 2013-present Cole Bemis under the MIT License. Both are in LICENSE-Lucide.txt (the package's LICENSE).
  Source: the npm package lucide-static 1.70.0 (https://registry.npmjs.org/lucide-static/-/lucide-static-1.70.0.tgz,
  sha1 5e8408d50248890e4262e79b8f7477056bbc2400, sha256 of the tarball
  3d1f09df1c468abe512ee6d6596db0dc773fa46c61050e365f0c5fee5120f16a), file font/lucide.ttf (986,208 bytes, sha256
  a17478dfd261662eae3f64fd71c1a05465c70018b46a5d852af6a23459921d15). The code points Studio uses are generated
  into src/theme/lucide.rs from the package's font/codepoints.json.
