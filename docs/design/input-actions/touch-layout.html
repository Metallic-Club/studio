Automatic touch controls

One thumbstick on the left, buttons for actions marked ShowOnTouch on the right. One rule places every control from the safe area, so the same game fits a small phone and a tablet. Sizes are in dp (1 dp = 1/160 inch).

Values

Stick zoneLeft half of the safe area, below the top 15%. A touch that starts on a button or on UI does not make a stick.
Stick baseRadius 60 dp (phone), 70 dp (tablet). Floating by default; Fixed is a player setting (centre 24 dp from the safe-area corner, plus the radius).
KnobDiameter 56 dp (phone), 65 dp (tablet). Travel limit R. Past R the base follows the finger.
Dead zone0.15 R (9 dp on a phone), then rescaled to start from 0.
OpacityHint ring 35%. Base while held 55%. Buttons 90%. A player slider from 25% to 100% scales all of them.
Primary button72 dp phone, 84 dp tablet. Bottom-right corner, 24 dp margin from the safe area.
Secondary buttons56 dp phone, 64 dp tablet. Ring 1 is 84 dp from the primary centre (angles 180, 130, 80 degrees), ring 2 is 152 dp (175, 140, 105). The tablet multiplies both radii by 1.167.
LimitsNever below 48 dp. At least 8 dp between edges. At least 16 dp from the safe-area edge. At most 6 buttons; Studio warns above 5.
