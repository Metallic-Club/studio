# Metallic Engine + Studio Milestone 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Our own Rust engine plays the Parkour game (1A), and Metallic Studio creates it from a template, edits it and plays it (1B), on Windows 11.

**Architecture:** A Cargo workspace. `metallic_core` holds the Roblox-style Instance tree and its text format; `metallic_render` draws Parts with wgpu; `metallic_physics` wraps Rapier and the Humanoid controller; `metallic_script` runs sandboxed Luau with the Roblox-named API; `metallic_runtime` ties them into a game loop used by both apps; `metallic_player` and `metallic_studio` are the two binaries. Templates are project folders under `templates/`.

**Tech Stack:** Rust 1.99 (stable, edition 2024), wgpu, winit, gilrs, rapier3d, mlua (feature `luau`), egui/eframe (wgpu backend), serde + ron, cargo-deny.

**Spec:** `docs/superpowers/specs/2026-10-30-metallic-studio-design.md`

## Global Constraints

- Names: "Metallic Engine", "Metallic Studio", "Metallic player"; never "Metallic Studios". Brand: graphite/charcoal, silver/titanium, restrained violet; no neon, glow, shields or starbursts.
- Icon/splash only from `branding/`; nothing else may embed a copy (build code reads or `include_bytes!`s the file there).
- Dependencies: permissive licences only (MIT, Apache-2.0, BSD-2/3, Zlib, ISC, Unicode-3.0, MPL-2.0); `cargo deny check licenses` must pass. No engine crates (bevy, fyrox, godot bindings).
- Units are studs. Humanoid defaults: Health 100, MaxHealth 100, WalkSpeed 16, JumpPower 50, MaxSlopeAngle 89; gravity 196.2 studs/s².
- Luau sandbox: per-resume budget 0.1 s, memory cap 256 MB per VM, no `io`, `os` (except `os.clock`, `os.time`), `debug`, `loadstring`, `load`, `getfenv`, `setfenv`, `require`, `dofile`, `collectgarbage` beyond `"count"`.
- Script error text: `<Instance full name>:<line>: <message>` (e.g. `Workspace.Lava.Script:3: attempt to index nil with 'Health'`).
- Perf: Parkour >= 60 fps at 1080p high on this PC (RTX 3060 Ti, Ryzen 5 5500, 32 GB); stress scene 5,000 Parts >= 60 fps. Integrated-graphics 30 fps: "not verified" unless run on such a machine.
- Git: repo `<home>\Documents\metallic-studio`, branch `studio/m1-engine-20261030` from `studio/design-20261030`; commits with `-c user.name=oncoursemail -c user.email=84545815+oncoursemail@users.noreply.github.com`, message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; never push `main`, never force-push, never configure git identity.
- PC load: daytime (08:00-24:00 America/Chicago) `cargo` with `-j 4`; night may use all cores. No pop-up windows: long runs via background shell, never `start`.
- Code clarity (owner, 2026-10-30): every crate has `#![warn(missing_docs)]`, a `//!` crate doc and `///` on every public item; no `unwrap()`/`expect()` outside tests; update ARCHITECTURE.md and doc comments in the same change as a public interface.
- Toolchain: `export PATH="$HOME/.cargo/bin:$PATH"` in Git Bash. Commands from repo root:
  - test: `cargo test --workspace`
  - lint: `cargo clippy --workspace --all-targets -- -D warnings`
  - licences: `cargo deny check licenses`

## Review Focus

1. A script with `while true do end` or one that allocates without end is stopped (timeout / memory message) while other scripts keep running. Tests in Task 6.
2. A runtime error prints the global error format to Output and stops only that script thread. Test in Task 7.
3. Stop while `task.delay`/`task.wait` callbacks are pending: nothing fires after Stop; Play again connects each handler exactly once. Tests in Tasks 7 and 11.
4. New project from template into a folder with spaces and non-ASCII characters works; a non-empty folder is refused and left untouched. Test in Task 9.
5. A dead character touching lava again, or reaching the finish twice, triggers nothing extra; falling off the map respawns once at the last checkpoint. Tests in Tasks 5 and 8.
