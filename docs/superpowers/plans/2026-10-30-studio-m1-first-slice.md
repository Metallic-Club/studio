# Metallic Studio Milestone 1 (First Slice) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Metallic-branded editor on Windows 11 where a creator makes a new game from the Parkour template, edits the level and presses Play; the template's game logic is Luau.

**Architecture:** The repo root becomes a fork of Godot 4.7.2-stable (merged in so upstream fixes can still be merged later). All Metallic runtime code lives in one engine module, `modules/metallic`: a sandboxed Luau VM (Roblox's Luau vendored under `thirdparty/luau`), Roblox-style `ServerScript`/`ClientScript` nodes run by a `ScriptService`, an in-process `RemoteEvent` between a server VM and a client VM, a native `MetallicCharacter`, and a `TemplateLibrary` used by the start screen. Templates are plain project folders under `templates/`.

**Tech Stack:** C++ (Godot 4.7.2 engine, SCons, MSVC from Visual Studio Build Tools 2026), Luau (MIT, Roblox/luau latest release tag), doctest (Godot's built-in `--test`), Python 3.15 for tools, Jolt physics (built into Godot), Kenney CC0 art.

**Spec:** `docs/superpowers/specs/2026-10-30-metallic-studio-design.md`

## Global Constraints

- Name "Metallic" / product "Metallic Studio" (never "Metallic Studios"); graphite/charcoal, silver/titanium, restrained violet; no neon, glow, shields or starbursts; emblem symbol-only.
- Icon and splash come only from `branding/` (one place, easy to swap); no copies of brand images committed elsewhere except files generated by `branding/apply_branding.py`.
- No stock Godot name, logo or default theme visible on the start screen, the template dialog, the editor's main window/menus, or the running game window.
- Keep Godot, Luau, Jolt and Kenney licence notices in source and in the packaged `LICENSES/` folder; the About dialog's third-party licences stay.
- No server addresses, user names, keys or tokens in git. Never push `main`; branch `studio/m1-first-slice-20261030` from `studio/design-20261030`; no force-push.
- Commits use the per-command identity `-c user.name=oncoursemail -c user.email=84545815+oncoursemail@users.noreply.github.com` and end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- PC load: full engine compiles only 00:00-08:00 America/Chicago (`-j10`); in the daytime incremental builds only, `-j4`. Stop and report if C: has under 8 GB free (22 GB free on 2026-10-30).
- Creator-facing scripting is Luau only. GDScript stays in the engine but must not be offered in the template dialog or template files; C# (.NET) is not built.
- Performance: >= 60 fps at 1080p high settings on this PC (RTX 3060 Ti, Ryzen 5 5500, 32 GB) in the Parkour template. The 30 fps integrated-graphics target is reported "not verified" unless run on such a machine.
- Build/test commands (from repo root, Git Bash):
  - build: `scons platform=windows target=editor tests=yes dev_build=no -j4`
  - tests: `bin/godot.windows.editor.x86_64.exe --headless --test --test-case="*[Metallic]*"`

## Review Focus

1. A Luau script with an endless loop (`while true do end`) must not freeze the editor or game: it is stopped with "Script timeout: exhausted allowed execution time" and other scripts keep running. Test in Task 3.
2. A script runtime error (indexing nil, a renamed node) prints `<script path>:<line>: <message>` to Output, stops only that script, and never crashes the game. Test in Task 4.
3. Pressing Stop while `task.delay`/`task.wait` callbacks are pending: nothing fires after Stop and pressing Play again starts clean (no doubled connections). Test in Task 4.
4. Creating a template into a folder with spaces or non-ASCII characters works; into a non-empty folder is refused with a clear message, never overwriting. Test in Task 7.
5. Falling or touching lava again while already dead respawns once, at the last checkpoint; touching the finish twice reports one finish. Tests in Tasks 6 and 8.
